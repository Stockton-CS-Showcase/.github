# Stockton CS Showcase

A place for Stockton University students (Galloway, NJ) to share personal software projects they built from scratch. Run by [Robert Poley](https://github.com/Sinbhad).

## Why this exists

Most project boards get flooded with AI-generated templates and class homework. This org is strictly for side projects written by hand by Stockton students who actually know how their code works.

## Rules

1. **One repository per student.** Pick one personal project you want to share here.
2. **No AI code.** Write your project yourself. Reading docs, textbooks, man pages, and Stack Overflow is normal; having ChatGPT, Copilot, Claude, or Cursor write your files is not.
3. **Personal projects only.** Don't upload active Stockton homework or lab assignments so nobody runs into academic integrity trouble. If you took an idea from a class and kept building it on your own after the semester ended, that's fine.
4. **Include a README.** Put clear build or run steps in your repository and be able to explain how your code works.

## Joining

If you're a Stockton student and want to add your project, reach out to [Robert Poley](https://github.com/Sinbhad) (`poleyrobert@gmail.com`) to get added as a contributor, then put your repository in this org.
